# Karing

Karing is an MVP-supported client for VLESS TCP REALITY, VLESS gRPC REALITY,
and Trojan TLS.

1. Import the HTTPS subscription issued by the operator.
2. Refresh the profile and select one supported transport.
3. Verify the VPN connection, external IP, and bidirectional traffic.

In the tested Karing version, XHTTP REALITY may be absent from the subscription
or fail to connect. Do not add URI conversion layers; report the result and use
a supported profile.
