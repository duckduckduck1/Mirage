# Hiddify

Hiddify is an MVP-supported client for VLESS TCP REALITY, VLESS gRPC REALITY,
and Trojan TLS.

1. Obtain one HTTPS subscription URL from the operator.
2. Add it to Hiddify as a subscription URL.
3. Refresh it and confirm that TCP REALITY, gRPC REALITY, and Trojan TLS appear.
4. Connect, verify the external IP changes, and open an HTTPS website.

XHTTP REALITY can be absent or time out in the tested Hiddify versions. This is
a known client limitation, not a reason to alter the server.
