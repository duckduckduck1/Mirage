# Восстановление из архива

Mirage использует только штатный SQLite-архив Marzban. По официальной процедуре
он восстанавливает содержимое `/opt/marzban` и `/var/lib/marzban`, затем требует
явный `marzban restart`.

1. Сначала разверните базовую инфраструктуру одним из сценариев установки.
2. Поместите полученный архив за пределами Git checkout, сделайте владельцем
   `root` и ограничьте доступ правами `0600`.
3. Выполните сценарий, передав абсолютный путь:

```bash
ansible-playbook -i inventory/localhost.yml playbooks/restore.yml \
  -e 'marzban_restore_archive=/root/restore/marzban-backup.tar.gz'
```

Playbook принимает только обычный root-owned tar-архив, в котором есть пути
`/opt/marzban` и `/var/lib/marzban`; другие пути отклоняются до распаковки.
После восстановления он повторно применяет инфраструктурные роли, перезапускает
Marzban и ожидает Unix-сокет панели.

Проверьте панель, число пользователей, HTTPS-подписку, бота и внешний клиентский
трафик. Непроверенный архив не считается резервной копией.
