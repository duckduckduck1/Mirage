# Совместимость клиентов

| Клиент | TCP REALITY | gRPC REALITY | Trojan TLS | XHTTP REALITY |
|---|---:|---:|---:|---:|
| Hiddify | Да | Да | Да | Нет |
| Karing | Да | Да | Да | Нет |
| V2RayTun | Нет | Нет | Нет | Нет |
| V2Box | Нет | Нет | Нет | Нет |
| Streisand | Нет | Нет | Нет | Нет |
| OneXray | Нет | Нет | Нет | Нет |
| Закреплённый Xray-core | Не проверялся | Не проверялся | Не проверялся | Да |

«Да» означает, что импорт, VPN, смена внешнего IP и пользовательский трафик
прошли проверку на зафиксированных версиях. «Нет» не означает дефект сервера:
для неподдерживаемых приложений пользовательский трафик не был подтверждён даже
на контрольных профилях.

Ограничение снимается только после новой фактической проверки конкретной версии
клиента и ОС: импорт, подключение, IP, HTTPS, Telegram/Instagram и стабильный
двунаправленный XHTTP-трафик при применимости.
