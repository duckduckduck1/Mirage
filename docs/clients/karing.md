# Karing

Karing — поддерживаемый клиент MVP для VLESS TCP REALITY, VLESS gRPC REALITY и
Trojan TLS.

1. Импортируйте HTTPS-подписку, выданную оператором.
2. Обновите профиль и выберите один из трёх поддерживаемых транспортов.
3. Проверьте VPN-подключение, внешний IP и двунаправленную передачу данных.

В проверенной версии Karing XHTTP REALITY может не отображаться в подписке или
не устанавливать соединение. Не добавляйте отдельные URI-конвертеры: сообщите
оператору результат и используйте поддерживаемый профиль.
