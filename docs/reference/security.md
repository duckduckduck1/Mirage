# Безопасность

- Секреты находятся только в root-only файлах вне Git checkout.
- В Git и публичной документации запрещены токены, пароли, ключи, сертификаты,
  реальные IP, домены, UUID, subscription-ссылки и backup-архивы.
- Администратор входит на VPS по SSH-ключу; парольный вход отключается только
  после проверки второго key-based сеанса и rollback-механизма.
- UFW открывает только утверждённые TCP-порты; Docker настраивается только на
  чистом VPS или после отдельной проверки существующей установки.
- Панель Marzban работает через Caddy и Unix-сокет, без публичного внутреннего
  HTTP-порта.

При подозрении на утечку немедленно отзовите и перевыпустите затронутый секрет,
затем проверьте журналы и резервные копии. Не вставляйте секрет в отчёт об
инциденте.
