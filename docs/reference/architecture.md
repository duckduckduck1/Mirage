# Архитектура

Marzban отвечает за панель, SQLite, генерацию подписок, Telegram-бот и штатные
резервные копии. Xray-core обслуживает четыре инбаунда, Caddy публикует панель
и подписки через отдельный HTTPS-порт и штатный Unix-сокет Marzban.

Сервер не публикует внутренний HTTP-порт Marzban. Для Caddy и Trojan используется
одна выпущенная по DNS-01 пара сертификата и ключа. Xray-core закреплён на
проверенной версии, а временное исправление А-13 существует как минимальный
производный образ до официального upstream-релиза.

Пользователь получает одну ссылку. Изменения инбаундов и лимитов выполняются на
сервере и приходят через обычное обновление подписки.
