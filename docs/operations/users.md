# Пользователи и Telegram-бот

Пользователями управляют веб-панель Marzban или её штатный Telegram-бот. Mirage
не создаёт отдельную админ-панель и не вызывает API от имени оператора.

При выдаче доступа:

1. Создайте пользователя через бот или панель.
2. Назначьте все четыре утверждённых инбаунда.
3. Укажите срок и лимит трафика.
4. Передайте пользователю единственную HTTPS-ссылку подписки через безопасный
   канал.

Для блокировки используйте штатную приостановку или удаление пользователя.
Пользователь обновляет ту же подписку; новую ссылку выдавать не требуется, пока
не меняется сама учётная запись.
