# Резервные копии

Marzban создаёт и доставляет резервные копии штатным `backup-service`. Настройку
расписания, немедленный backup и изменение доставки выполняйте только по
[официальному руководству Marzban](https://gozargah.github.io/marzban/ru/examples/backup).

Минимальный регламент:

- хранить полученные архивы вне VPS и вне Git;
- периодически проверять получение архива;
- после каждого изменения процедуры выполнять восстановление на временном
  сервере;
- после распаковки обязательно делать `marzban restart`.

Не публикуйте архивы, SQLite-файлы, `.env` или их содержимое в issue, чатах и
системах CI.
