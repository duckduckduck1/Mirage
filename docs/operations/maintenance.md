# Обслуживание

Перед изменением Marzban, Xray-core, iOS или клиентского приложения сохраните
проверенный backup и запланируйте повторную матрицу клиентов. Версия Xray-core
закреплена: её обновление допускается только после полной проверки поддерживаемых
транспортов.

Повседневно проверяйте:

- доступность панели и HTTPS-подписки;
- работу Telegram-бота;
- доставку резервных копий;
- запуск Marzban, Caddy и Docker после перезагрузки VPS.

На общем VPS не используйте `docker system prune`, широкие удаления и действия
над контейнерами, томами или сетями, не принадлежащими Mirage.
