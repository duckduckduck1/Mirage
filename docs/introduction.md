# О Mirage

Mirage 2.0 — инфраструктурный проект для развёртывания Marzban на одном VPS.
Marzban остаётся источником истины для пользователей, подписок, Telegram-бота и
штатных резервных копий; Mirage автоматизирует только подготовку ОС и
воспроизводимое применение утверждённой конфигурации.

Каждый пользователь получает одну HTTPS-ссылку подписки с четырьмя профилями:
VLESS TCP REALITY, VLESS gRPC REALITY, VLESS XHTTP REALITY и Trojan TLS.

Поддерживаемый минимум MVP — Hiddify и Karing для TCP REALITY, gRPC REALITY и
Trojan TLS. Перед выдачей доступа прочитайте [совместимость клиентов](/clients/compatibility).

## Принципы

- Не добавлять собственные обёртки над API Marzban.
- Не помещать рабочие данные и секреты в репозиторий.
- Не менять общий VPS или чужие Docker-объекты автоматически.
- Считать сценарий завершённым только после фактической проверки.
