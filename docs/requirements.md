# Требования

Для поддерживаемого сценария нужен новый 64-битный VPS с Ubuntu 22.04 LTS,
доступом root по SSH и открытыми TCP-портами из [справочника](/reference/ports).

Подготовьте вне Git:

- публичный SSH-ключ администратора;
- отдельные root-only файлы для DNS, ACME и Telegram-данных;
- постоянное DNS-имя, управляемое владельцем;
- рабочую учётную запись Marzban, создаваемую только штатной CLI;
- внешний канал для хранения резервных архивов.

Для приёмки чистого VPS используйте отдельные тестовые DNS- и Telegram-данные:
не перенаправляйте рабочее имя и не запускайте второй сервер с боевым токеном
бота.
