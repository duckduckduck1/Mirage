# 3. Доставка через подписку и миграция через домен + бэкап

- **Статус:** принято
- **Дата:** 2026-06-25

## Контекст

Главный приоритет проекта — смена сервера/IP без действий со стороны друзей.
Блокировки IP происходят регулярно, переезд должен быть рутиной, а не авралом с
рассылкой новых конфигов каждому.

## Решение

Друзьям раздаём **subscription-ссылку**, а не голый конфиг. Подписку отдаёт сам
VPS (3x-ui), но адрес ссылки привязан к **домену** `sub.ДОМЕН`, а не к IP.

Переезд на новый сервер:

1. Поднять новый VPS (Terraform) и настроить (Ansible).
2. Восстановить `x-ui.db` из бэкапа — те же клиенты и UUID.
3. Переключить A-запись `sub.ДОМЕН` на новый IP (низкий TTL DNS).
4. Клиенты при обновлении подписки сами переходят на новый сервер.

## Рассмотренные альтернативы

- **Голые конфиги `vless://`** — при смене IP мертвы, нужна рассылка всем. Отказ.
- **Подписка по IP без домена** — переезд снова рвёт ссылку. Отказ.
- **Отдельный always-on control-хост для подписок** — надёжнее (VPN-сервер
  полностью одноразовый), но сложнее и дороже. Отложено как возможное улучшение.

## Последствия

- **Плюс:** переезд незаметен для друзей; IP становится расходником.
- **Плюс:** домен даёт заодно валидный TLS-сертификат для подписки.
- **Минус:** нужен домен и управляемый DNS; при переезде обязателен восстановленный
  бэкап `x-ui.db`, иначе подписки разъедутся. Бэкап — критичный артефакт.
