# 5. Провайдер VPS — Timeweb Cloud (европейский ДЦ), осознанный компромисс

- **Статус:** заменён [ADR-0006](0006-manual-provisioning-defer-terraform.md) (выбран reseller-VPS вместо Timeweb)
- **Дата:** 2026-06-25

## Контекст

Действуют три ограничения одновременно:

1. Оплата возможна **только картами РФ / СБП** (зарубежной картой — нельзя).
2. Сервер-выход обязан быть **за пределами РФ** (Германия/Нидерланды/Финляндия),
   иначе он сам внутри периметра фильтрации и не обходит блокировки.
3. Решение [ADR-0004](0004-iac-from-the-start.md) требует **API + Terraform** для
   IaC с самого начала.

Под все три условия сразу подходит мало кто. Нейтральные по юрисдикции провайдеры
(Hetzner, Vultr) не принимают карты РФ напрямую — только посредники (~7% комиссии)
или зарубежные виртуальные карты. Aeza — нет прямой оплаты картой РФ. Reseller-
серверы из магазинов — без API (ломают Terraform) и с «грязными» IP.

## Решение

Стартуем на **Timeweb Cloud**, облачный сервер в европейской локации
(**Амстердам** или Франкфурт). Оплата картой РФ/СБП. Управление — через
**официальный Terraform-провайдер** `timeweb-cloud/timeweb-cloud`.

Timeweb уникально закрывает все три условия: карты РФ + европейский ДЦ +
официальный Terraform.

## Рассмотренные альтернативы

- **Hetzner / Vultr (нейтральные)** — безопаснее по юрисдикции, полный Terraform,
  но оплата из РФ только через посредников/виртуальные карты. Отложено до решения
  вопроса с оплатой.
- **Aeza** — EU-локации и не-РФ юрисдикция, но прямой оплаты картой РФ нет.
- **Reseller-серверы (магазины)** — нет API → несовместимо с Terraform; IP часто
  заранее в блок-листах; нет возврата средств.
- **VDSina / RUVDS** — карты РФ есть, но нет официального Terraform-провайдера.

## Последствия

- **Плюс:** лёгкая оплата картой РФ; официальный Terraform; европейский IP, а
  блокировка VPN смягчается маскировкой Reality/FakeTLS и готовностью к миграции.
- **Риск (юрисдикция/ToS):** Timeweb — компания РФ, подчиняется 149-ФЗ и 276-ФЗ.
  Использование сервера для обхода официальных блокировок формально против их
  правил — «серая зона». Возможна блокировка аккаунта или сотрудничество с РКН
  (особенно из-за MTProxy под `vk.ru`).
  - **Митигация:** миграция наготове
    ([ADR-0003](0003-subscription-delivery-and-migration.md)); не держать на
    сервере лишних секретов/данных.
- **Риск (IP):** европейские диапазоны росс. провайдеров известны → возможен бан по
  IP (L3). Митигируется дешёвой миграцией.
- **План выхода:** при появлении зарубежного способа оплаты переезд на
  нейтрального провайдера остаётся штатным сценарием по дизайну миграции.
